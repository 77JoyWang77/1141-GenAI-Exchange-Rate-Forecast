資料庫處理

本頁介紹如何將爬取的匯率資料持久化到資料庫，作為後續分析與模型訓練的基礎。 我們使用 MySQL 搭配 SQLAlchemy 或 pymysql 進行資料儲存，並規劃了表格結構來管理每日匯率。

📌 資料

  • 來源：中央銀行統計資料庫
  • 使用套件：
    • requests：從 API 取得匯率資料
    • pandas：資料清理與格式轉換
    • SQLAlchemy：資料庫 ORM 與連線
    • mysql-connector-python：MySQL 資料庫驅動
    • plotly：匯率折線圖與互動式圖表
    • Dash：提供互動式圖表介面
    • Flask：網站後端框架，整合前後端

🛠 資料庫流程

  1. 透過中央銀行 API 取得每日、每月、每年匯率資料
  2. 使用 pandas 將資料清理並轉為寬表格格式
  3. 利用 SQLAlchemy 連接 MySQL 資料庫
  4. 將匯率資料寫入 bp01d01_rates、bp01m01_rates、bp01y01_rates 三張表
  5. 透過 Flask 提供資料查詢、圖表展示 API
  6. 使用 Dash + Plotly 建立互動式折線圖
