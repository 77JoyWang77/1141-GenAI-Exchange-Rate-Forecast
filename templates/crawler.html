匯率爬蟲

本頁介紹如何透過 Python 爬蟲自動收集匯率資料，作為專案後續分析、建模與預測的基礎數據來源。 爬蟲定期從目標網站擷取最新匯率資料，並轉換成結構化格式，方便儲存與分析。

📌 資料

  • 來源：台灣銀行牌告匯率
  • 更新頻率：刷新頁面時自動更新
  • 使用套件：
    • requests：發送 HTTP 請求
    • BeautifulSoup (bs4)：HTML 解析
    • pandas：表格資料整理
    • plotly：匯率趨勢圖繪製

🛠 爬蟲流程

  1. 發送 HTTP 請求至匯率網站
  2. 利用 BeautifulSoup 解析 HTML 網頁
  3. 擷取日期、幣別、買入價與賣出價資料
  4. 將資料整理為 Pandas DataFrame
  5. 存入資料庫進行後續分析
