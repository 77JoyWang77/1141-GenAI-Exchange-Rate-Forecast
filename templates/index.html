匯率預測分析平台

基於 Python 的
匯率預測分析平台

中央大學資工三A 王昭尹 生成式人工智慧與Python程式設計跨域應用 期末報告

本專案透過 Python 技術實現匯率資料自動化收集、儲存及預測， 並利用 Flask 搭建視覺化網站，未來可部署至 Kubernetes（K8s）實現擴展與自動化。

🛠 核心特色

匯率資料爬蟲

利用 Python 爬蟲自動化收集即時及歷史匯率資料，為後續資料分析提供可靠數據來源。

資料庫儲存

使用 MySQL 資料庫設計結構化表格，保存並管理匯率數據，支持高效查詢與更新。

LSTM 模型預測

利用長短期記憶網絡（LSTM）對匯率進行時間序列建模，提供趨勢預測與決策支持。

Flask 與 K8s 部署

以 Flask 架設可視化網站，並預留 Kubernetes 容器化部署設計，方便擴展與自動化。

🔍 實作流程

  1. 使用爬蟲定期取得匯率資料

  2. 將資料儲存至 MySQL 資料庫

  3. 透過 LSTM 模型進行時間序列預測

  4. 以 Flask 建立視覺化網站

  5. 可延伸至 Kubernetes 自動化部署
